## 生命周期补充验收

在独立测试目录中，先安装并调用最终发布的 0.1.0，再将仅修改版本号的私有副本升级为 0.1.1。该副本没有改变插件脚本、用法文档或示例，也未作为新版本发布。升级成功后，旧安装修订号、旧调用契约和文件校验不匹配的候选包均被拒绝；原有绑定不变，已安装插件仍可正常执行。

随后验证停用会拒绝新的调用，重新启用后恢复执行。再通过正常安装流程恢复原始 0.1.0，确认清单字节及包摘要与发布文件一致，并再次执行成功。

移走测试目录中的插件源文件后，已安装的两个插件仍可运行。宿主正常退出后，使用相同数据目录、工作区和会话冷启动，确认恢复后的 0.1.0 绑定与报告仍正确。三个任务共完成 14 次独立插件进程执行，每个原进程均追踪至完成、退出码 0；两次宿主关闭均正常退出，未遗留受管进程。

本次核对了配置摘要和状态世代标识保持一致，但没有验证非空配置或业务状态数据迁移；停用检查不包含正在执行的调用或停用状态下的冷启动。

## 验证边界

本轮实际宿主环境为 Linux x86_64。最终原生验收使用本地确定性调用驱动，不调用外部模型；它验证真实宿主与插件执行，不证明生成模型的推理或长程记忆能力。此前真实模型的初稿通过基础调用，但独立测试发现了问题，因此没有直接作为成品签收。

macOS、Windows 尚无原生安装验收。本轮不声称完整 CommonMark 支持、任意并发恶意文件变动隔离或跨平台全部通过。

JSON 与 Markdown 的详细输入、输出、错误和语法范围分别见插件使用说明。输入文件不应被修改，已有输出不得覆盖；遇到无法完整处理的输入，应保留明确的拒绝或未检查状态，而不是报告完整成功。
