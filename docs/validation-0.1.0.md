# 首批插件 0.1.0 验收记录

- 两个插件均由 wecode 完成初始实现；独立审查发现边界问题后，修复并重新验收最终文件。
- 仓库共 60 项单元测试通过。JSON 插件另有 35 项语义检查和 15 项输出保护、限额、确定性检查通过。
- Markdown 插件另有 25 项独立检查通过，包含本地相对路径、片段锚点、代码围栏、输出符号链接、短读及长行扫描。500,000 个未闭合方括号的实际脚本检查正常完成。
- 最终文件在真实 wecode 原生宿主中完成安装、能力查询、调用、原进程完成与报告读取。报告完整内容、输入摘要和源码文件均核对一致；宿主正常退出，未遗留受管进程。
- 发布目录、清单和校验记录绑定到同一份最终文件。校验记录仅是维护者核验后的声明，不是自动签发的安全认证。

## 验证边界

本轮实际宿主环境为 Linux x86_64。最终原生验收使用本地确定性调用驱动，不调用外部模型；它验证真实宿主与插件执行，不证明生成模型的推理或长程记忆能力。此前真实模型的初稿通过基础调用，但独立测试发现了问题，因此没有直接作为成品签收。

最终修复版本的升级、停用与冷启动尚未重新执行，记录保持未验证。macOS、Windows 也尚无原生安装验收。本轮不声称完整 CommonMark 支持、任意并发恶意文件变动隔离或跨平台全部通过。

JSON 与 Markdown 的详细输入、输出、错误和语法范围分别见插件使用说明。输入文件不应被修改，已有输出不得覆盖；遇到无法完整处理的输入，应保留明确的拒绝或未检查状态，而不是报告完整成功。
